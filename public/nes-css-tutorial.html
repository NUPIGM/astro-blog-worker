NES.css 实战教程

一个只做「组件」的 8bit 像素风 CSS 框架：纯 CSS、零 JavaScript、约 30KB。 它给你红白机时代的按钮、对话框和进度条，但不给你栅格、不给字体、不给配色方案—— 布局和主题都得自己写。

这页教程里每个组件都是真实渲染的，不是截图。代码块右侧可以一键复制。

v2.3.0 纯 CSS 零 JS LICENSEMIT

01 · 安装

三种方式，选一种就行。学习阶段建议直接用 CDN，省掉构建流程。

A · CDN：一行 link

把这段放进 <head> 里，立刻可用。@2.3.0 锁定版本，避免以后升级把样式打乱。

<link href="https://unpkg.com/nes.css@2.3.0/css/nes.min.css" rel="stylesheet">

B · npm

进构建流程时用。包里还暴露了 sass 和 style 两个字段，想改主题色可以编译 Sass 源文件。

npm install nes.css
# 或
yarn add nes.css

# 然后在入口引入
import 'nes.css/css/nes.min.css'

C · 字体：缝合像素字体

NES.css 不带字体。官方推荐 Press Start 2P，但它只有拉丁字形——中文会静默掉回系统字体， 于是「标题像素、正文宋体」的割裂感就出来了。本项目改用 缝合像素字体 Fusion Pixel Font： 同一套文件同时覆盖中英文与符号，标题和正文终于同族。

/* 400 原版 + 700 官方算法粗体，两个文件放本地 fonts/ 目录 */
@font-face{
  font-family:"Fusion Pixel";
  src:url("fonts/fusion-pixel-12px-proportional-zh-hans.woff2") format("woff2");
  font-weight:400; font-style:normal; font-display:swap;
}
@font-face{
  font-family:"Fusion Pixel";
  src:url("fonts/fusion-bold-pixel-12px-proportional-zh-hans.woff2") format("woff2");
  font-weight:700; font-style:normal; font-display:swap;
}

body{
  font-family:"Fusion Pixel","PingFang SC","Microsoft YaHei",sans-serif;
}
/* 标题不再需要单独的西文像素字体，中英文同一族 */
.pixel{ font-family:"Fusion Pixel",monospace; }
为什么是「12px 比例模式 / 简体中文」这一版？像素字体有 8 / 10 / 12 三档设计尺寸， 以及「等宽 / 比例」两种宽度模式。比例模式的字距与行高更自然、更适合正文， 官方也建议无特殊需求优先用它；zh_hans 版的汉字取自《通用规范汉字表》写法。 本项目实际使用的 610 个字符（含中英文、标点、→ ★ · 等符号）经 cmap 校验全部覆盖，零缺字。
代码块故意不换：pre 与行内 code 仍走系统等宽（SF Mono / Menlo / Consolas）。 原因有二：比例字体会破坏代码缩进对齐；等宽模式的像素字在 12.5px 这种非整数倍尺寸下会糊。 想要全站像素化，把 .code pre 与 code 的 font-family 换成 同系列的 monospaced 文件即可。

02 · 核心思路

先理解一件事，后面所有组件都不会用错：NES.css 里几乎所有组件都是一张「带 4px 像素边框的盒子」， 差别只在边框画法与内部 padding。所以它才敢只做组件、不做布局。

于是你要自己补三样东西：栅格、间距、主题色。这页用的是最朴素的 CSS Grid + 一个 16px 的棋盘背景。

LAYOUT IS YOUR JOB · 16px 像素网格

这个页面的底纹就是两条 16px 重复渐变，成本极低，但立刻有了「屏幕像素感」：

body{
  background-color:#f4f1e8;
  background-image:
    linear-gradient(rgba(33,37,41,.05) 1px, transparent 1px),
    linear-gradient(90deg, rgba(33,37,41,.05) 1px, transparent 1px);
  background-size:16px 16px;
}

<div class="nes-container with-title">
  <p class="title">标题</p>

<!-- 加圆角 / 加暗色 -->
<div class="nes-container with-title is-rounded">...</div>

注意：is-rounded 和 is-dark 都能叠加，但两者叠加时阴影与边框会重绘一次 （源码里有专门为 .is-rounded.is-dark 写的组合选择器）。别指望只写 is-rounded 就自动适配暗色。

04 · 按钮 nes-btn

四色语义 + disabled。按钮的「按下」效果是 4px 位移 + 阴影消失，纯 CSS，不需要 JS。

<button type="button" class="nes-btn">Normal</button>
<button type="button" class="nes-btn is-primary">Primary</button>
<button type="button" class="nes-btn is-success">Success</button>
<button type="button" class="nes-btn is-warning">Warning</button>
<button type="button" class="nes-btn is-error">Error</button>
<button type="button" class="nes-btn is-disabled">Disabled</button>
易错点：一定要写 type="button"。默认 type 是 submit， 放在表单里点一下就提交了。is-disabled 只是样式上禁用，事件照样触发—— 真要禁用请同时加 disabled 属性。

06 · 表单

这是 NES.css 里结构要求最严的部分：复选框和单选框必须自带 <span> 兄弟节点， 图标是画在 span 上的；下拉框必须外包一层 .nes-select，因为箭头是用容器伪元素画的。

<!-- 输入框：放在 .nes-field 里才有上下间距 -->
<div class="nes-field">
  <label for="name">用户名</label>
  <input type="text" id="name" class="nes-input">
</div>
<input class="nes-input is-success">   <!-- 四态：is-success / is-warning / is-error / is-disabled -->
<textarea class="nes-textarea"></textarea>

<!-- 下拉框：必须外包 .nes-select，否则箭头不出现 -->
<div class="nes-select is-success">
  <select>
    <option>EASY</option>
  </select>
</div>

<!-- 复选框：span 是必须的，方块底图靠它显示 -->
<label>
  <input type="checkbox" class="nes-checkbox" checked>
  <span>记住我</span>
</label>

<!-- 单选框：同理，同一组要共用 name -->
<label>
  <input type="radio" class="nes-radio" name="p" checked>
  <span>单人</span>
</label>

<!-- 暗色控件要用在深色背景上，否则白像素画在白底上等于没有 -->
<label>
  <input type="checkbox" class="nes-checkbox is-dark" checked>
  <span>暗色勾选</span>
</label>

<!-- 必补补丁：2.3.0 的 radio 未选中态没有任何图形 -->
<style>
  .nes-radio:not(:checked) + span::before{
    position:absolute; top:-2px; left:-20px; content:"";
    width:2px; height:2px; color:#212529;
    box-shadow:
      4px 0,6px 0,
      2px 2px,8px 2px,
      0 4px,10px 4px,
      0 6px,10px 6px,
      2px 8px,8px 8px,
      4px 10px,6px 10px;
  }
</style>
为什么 checkbox 一定要 span？因为 NES.css 把原生勾选框完全透明化（appearance:none + 1px + 裁剪）， 再用 input + span::before 配合几十个 box-shadow 方块在 span 上「画」出像素方框和勾。 少了 span，你只会看到一个 1px 的、被裁掉的残影。
框架缺陷（实测 2.3.0）：整套源码里只有 .nes-radio:checked + span::before， 没有未选中态的空环规则——所以默认情况下未选中的单选框是完全空白的，只能靠 checked 的那一个来暗示分组。 上面倒数那段 style 就是本页打的补丁（否则你会看到「单人」前面有圆圈、「双人」前面什么都没有）。 这是很少被文档提到的坑，遇到时别以为是自己的写法错了。

07 · 进度条 nes-progress

本质是原生 <progress> 加伪元素着色，所以 value/max 是标准属性，纯 HTML 就能动。

<progress class="nes-progress" value="70" max="100"></progress>
<progress class="nes-progress is-primary" value="50" max="100"></progress>
<progress class="nes-progress is-success" value="80" max="100"></progress>
<progress class="nes-progress is-warning" value="30" max="100"></progress>
<progress class="nes-progress is-error" value="10" max="100"></progress>
<progress class="nes-progress is-pattern" value="60" max="100"></progress>  <!-- 斜纹填充 -->
<progress class="nes-progress is-rounded is-primary" value="40" max="100"></progress>
想做出「血条随血量变色」的效果？不用改 CSS，JS 只改 class 和 value 两个东西就够了—— 样式全在前端，这正是「纯 CSS 框架」的好处。

08 · 徽章 nes-badge

三种形态：普通（单标签）、is-splited（双色拼接，适合「对象 + 版本号」）、 is-icon（图标徽章）。

NEW PASS WARN FAIL npm2.3.0
★ 
<span class="nes-badge"><span class="is-dark">NEW</span></span>

<!-- 双色拼接：两个 span，第一个是深色底座 -->
<span class="nes-badge is-splited">
  <span class="is-dark">npm</span><span class="is-primary">2.3.0</span>
</span>

<!-- 图标徽章 -->
<span class="nes-badge is-icon"><span class="is-warning">★</span></span>
反直觉的一个细节：.nes-badge 是 inline-block + 固定宽度 10.5em，里面的文字用 position:absolute; width:100% 铺满， 边框则靠四向 box-shadow 画出来。所以你不能把宽度改成 auto—— 一旦父级没有确定宽度，绝对定位的文字就失去基准，多个徽章会直接叠在一起。 要缩短只能按 em 指定宽度（本页顶部那几个小徽章就是这么压到 7em 的）。

12 · 对话框 nes-dialog

建议直接用原生 <dialog> 元素：遮罩、ESC 关闭、焦点锁定浏览器都帮你做了， NES.css 只负责外观。这是本框架里唯一需要一行 JS 的组件（showModal()）。

GAME OVER

是否从存档点继续？

 
<dialog class="nes-dialog is-rounded" id="game-dialog">
  <form method="dialog">
    <p class="title">GAME OVER</p>
    <p>是否从存档点继续？</p>
    <menu class="dialog-menu">
      <button class="nes-btn">取消</button>
      <button class="nes-btn is-primary">继续</button>
    </menu>
  </form>
</dialog>

<script>
  document.getElementById('open').onclick = () =>
    document.getElementById('game-dialog').showModal();
</script>
<form method="dialog"> 里的按钮会自动关闭对话框并把 value 写进 dialog.returnValue，不用自己写关闭逻辑。这就是为什么推荐它而不是手搓 div 弹窗。
遮罩是坏的（实测 2.3.0）：框架里写的是 .nes-dialog::-webkit-backdrop， 但浏览器只认标准的 ::backdrop，::-webkit-backdrop 这个伪元素并不存在。 结果是弹窗打开了、背景却不会变暗。补一行即可，本页就加了这句： .nes-dialog::backdrop{background:rgba(0,0,0,.35)}

16 · 六个常见坑

这些问题几乎每个用 NES.css 的人都会撞一次，提前知道能省两小时。

  • 字体不生效：框架自带 html{font-family:sans-serif} 的重置，你的 font-family 必须写在 link 之后，或用选择器压过它。
  • 尺寸全是 rem：在 html 上调字号会让所有组件等比缩放，但像素边框（4px）不跟着变，画风会崩。要缩放请整体用 transform:scale()。
  • 想改主题色：不要覆盖 .is-primary，会连同按钮、图标、进度条一起改。正确做法是编译 Sass，改 $color-primary 变量。
  • 图标对不齐：.nes-icon 是 inline-block 且带固定尺寸，混在文字里请加 vertical-align:middle。
  • 行高会变：换成缝合像素字体后，字形框是 1300 / -300 / 1200（上下 / 字身），默认行高约 1.33em，比 Press Start 2P 的约 2 紧得多。正文要显式补 line-height，否则中文会挤成一坨。
  • 非整数倍缩放会糊：像素字体按 12px 设计，用在 15px（1.25 倍）时每个像素落到 1.25 个物理像素上，边缘必然发虚。这不是 bug，是点阵字体的物理限制——想要锐利，字号请取 12 的整数倍（12 / 24 / 36px）。
  • 单选框未选中看不见：2.3.0 只画了 :checked 态，未选中的 nes-radio 是空白的，需要自己补空环（见第 06 节）。
需要深色站点？把 body 背景设成 #212529，然后所有组件加 is-dark。 框架没有全局的「深色模式开关」——is-dark 是逐组件生效的。
